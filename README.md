# placitum/modsec

Инспектор правил Placitum: OWASP Core Rule Set на движке Coraza. Смотрит запрос и ответ —
заголовки, строку запроса, тело — и отвечает вердиктом со счётом.

CRS встроен в бинарник, с диска читаются только профили: то, что отличает одну установку от
другой. Coraza — чистый Go, включая регулярные выражения, поэтому образ статический и без libc.

```
модуль ──► waf.req.modsec ──►  modsec  ──► allow | score | deny
                                 │
                                 ├── профиль: наборы SecLang поверх CRS
                                 ├── тело: из обменника по локатору
                                 └── просьбы соседей: смягчить порог, пропустить путь
```

## Что он умеет

- **Обе фазы.** Запрос и ответ — одним процессом, разными наборами правил.
- **Счёт, а не только отказ.** Аномальный счёт CRS уходит модулю вкладом в порог маршрута;
  безоговорочный отказ остаётся за правилами, которые помечены таким явно.
- **Просьбы соседей.** Отправитель канала действий может смягчить порог на доверенном пути или
  попросить пропустить служебный запрос — modsec применяет это только по правилу приёма в
  своём профиле.
- **Горячая замена правил.** Новое поколение профилей компилируется рядом и подменяет набор
  атомарно; битое поколение не применяется.

## Сборка и запуск

```sh
docker build -f deploy/Dockerfile -t placitum/modsec .
docker buildx build -f deploy/Dockerfile -t placitum/modsec \
  "https://github.com/exemt/placitum-modsec.git#develop"
```

Сборка прогоняет тесты и компилирует набор правил — опечатка в SecLang ловится здесь, а не
стартом контейнера. Что нужно рядом и все переменные — [INSTALL.md](INSTALL.md).
