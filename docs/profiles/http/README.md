# profiles/http

Набор правил транзакции HTTP: фазы 1–5, обе стороны. Каждый подкаталог — профиль, имя подкаталога и
есть имя профиля из `route.profile`.

| Профиль | Что это |
| --- | --- |
| `default` | CRS целиком (`REQUEST-*` и `RESPONSE-*`), уровень паранойи 1 |
| `strict` | То же, уровень паранойи 2. Расходится с `default` ровно одним файлом |
| `allow` | Фикстура: `SecRuleEngine Off`. Инспектор в наборе маршрута есть, правил не исполняется ни одного |
| `deny` | Фикстура: единственный профиль с `SecRuleEngine On` и безусловной блокировкой |

## Порядок файлов

Файлы включаются в лексическом порядке имён, поэтому нумерация значима:

| Файл | Что задаёт |
| --- | --- |
| `00-engine.conf` | Настройки движка: `DetectionOnly`, аудит в JetStream, разбор тела ответа |
| `10-crs-setup.conf` | Уровень паранойи и оба порога (входящий и исходящий) |
| `20-crs.conf` | Сам CRS: `REQUEST-*.conf` и `RESPONSE-*.conf` |
| `30-policy.conf` | Локальная политика поверх набора |

Уровень паранойи обязан быть выставлен до включения CRS: правила читают `tx.blocking_paranoia_level`
в фазе 1 в порядке объявления, и значение, назначенное после них, до них не дойдёт.

## Что профиль держит выключенным

`SecRuleRemoveByTag "attack-dos"` — защиту от DoS делает локальный слой модуля (`waf_local_rate` и
IP фильтр), и делает раньше: до публикации на шину. Оставить её здесь значило бы считать один
и тот же флуд дважды, причём второй раз уже после того, как он обошёлся дорого.

Больше ничего не выключено, и это разница с прежней раскладкой. `RESPONSE-980-CORRELATION` работает:
корреляция входящего счёта с исходящим требует обоих в одной транзакции, и теперь они в одной.

## Решение по счёту принимает модуль

`SecRuleEngine DetectionOnly` у всех штатных профилей: инспектор сообщает уверенность, отказывает
nginx по `waf_score_deny` своей фазы. Пороги CRS в `10-crs-setup.conf` — знаменатели калибровки
score, а не пороги блокировки (см. [`internal/verdict`](../../internal/verdict/README.md)).
Исходящий порог штатно ниже входящего: утечка стоит дороже подозрительного ввода, и правил на неё
меньше.
