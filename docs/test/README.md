# test

Модульные тесты Go-пакетов лежат рядом с исходниками (`_test.go` в каждом `internal/...`), по
конвенции языка. Этот каталог — для того, что не привязано к одному пакету:

- **Фикстуры сообщений** — тела запросов по классам нагрузки (без тела, JSON 8 КБ, multipart 256 КБ)
  на разных уровнях паранойи, нужные для измерений из
  «Что осталось измерить» (`docs/research/modsecurity-inspector.md`).
- **Замер латентности движка** — CPU-мс на транзакцию по этим классам; без него сайзинг
  (`internal/queue`, глубина очереди) и `timeout=` в объявлении инспектора назначаются наугад, см.
  «Сайзинг по процессору» (`docs/research/modsecurity-inspector.md`).
- **Интеграционные сценарии против реального движка** — негативные случаи из
  docs/inspectors.md#контракт (`docs/inspectors.md`): молчание, ответ после
  дедлайна, недоступное тело, — выполняемые против настоящего Coraza.
- **Сравнение вердиктов двух движков** (если появится вторая реализация) — доля расхождений на
  одинаковом наборе правил и трафике, см.
  seclang-engines.md#что-осталось-выяснить (`docs/research/seclang-engines.md`).

Появляется вместе с первым кодом на этапе 4, дополняется на этапе 6 (тело и его классы размера).
